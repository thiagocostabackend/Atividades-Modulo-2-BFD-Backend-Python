- `Associação-Agregação-Composição/` — exercícios sobre relações entre objetos
- `classes-objetos-herancas/` — exercícios sobre criação de classes e herança

- `Polimorfismo/` — exercícios demonstrando polimorfismo em métodos

## ▶️ Como executar
- Use Python 3.8+ (recomendado).
- Rode arquivos diretamente: `python <pasta>/<arquivo>.py` (por exemplo, `python Abstração/Sistema_Pagamentos.py`).

> Dica: abra o diretório no VS Code e execute com o terminal integrado para facilitar testes e depuração. 💡
